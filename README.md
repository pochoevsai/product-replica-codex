# Product Replica for Codex

A reusable Codex skill for researching an existing product and building an original, safer, improved alternative.

## What it covers

- product research and workflow mapping
- architecture, UI, backend, integrations
- vertical-slice implementation
- tests, accessibility, security, and reliability
- feature parity and visual comparison
- review-driven improvements
- distinct branding, launch checks, and deployment preflight

## Install

Copy this folder into your Codex skills directory:

```text
product-replica/
```

For project-local use, place it under `.codex/skills/product-replica/`. The skill includes standard-library Python helpers in `scripts/`.
